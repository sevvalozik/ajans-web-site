# Ajans web sitesi

Ajansın kendi sitesinin prototipi. Tek sayfa: `index.html`, proje sarmalındaki kareler `work/` klasöründe.

Canlı önizleme: GitHub Pages (Settings → Pages → main / root).

- Marka adı şimdilik yer tutucu (`sayfa`). Değiştirmek için `index.html` içinde `CONFIG = { BRAND: "sayfa" }` satırı.
- İletişim formu henüz bir e-postaya bağlı değil.
- Kütüphaneler CDN'den yükleniyor: GSAP, Three.js, Matter.js, Lenis.
